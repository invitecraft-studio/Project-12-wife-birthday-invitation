# Happy Birthday Bhagyashri (React + Vite)

Run locally:  npm install && npm run dev
Build:        npm run build   (output in dist/)
Serve build:  npm start       (Node server for dist/, uses PORT or 3000)
Vercel/Netlify: build command `npm run build`, output directory `dist`.

Edit all text (names, story, reasons, letter, gift message, coupons, birthday date) in src/data.json.
Images live in src/assets (intro.jpg = lotus opening page).
